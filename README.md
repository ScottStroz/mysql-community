This is the frontpage (README.md) of MySQL Community resources on GitHub, and elsewhere. 

You are on the footstep to one of the oldest and largest, international, deeply technical, often also passionate, caring and above all one of the strongest open source communities in the world: The MySQL Community, or as we also call it, the MySQL Ecosystem.

This page is edited by the MySQL Community team, currently: Heather, Lenka, Scott, Kailas, Lilly, and Henrik. You can learn more about us on [dev.mysql.com/community](https://dev.mysql.com/community). 

With the help of others, MySQL developers and community members, we've done our best to create a helpful and informative repository, that will guide you to the right place, whether you are creating your first app using MySQL as the database, or you are here with a patch that fixes a critical replication bug that had you waking up the night before Black Friday.

We hope you feel welcome. And now, with introductions taken care of, let us help you find what you came here to do or learn...

## Community discussions

We use GitHub Discussions to make it easier for the MySQL community to follow, join, and continue conversations around MySQL community priorities.

Visit [GitHub Discussions](https://github.com/mysql/mysql-community/discussions) to:

- Follow announcements from the MySQL Community team
- Participate in roadmap-related conversations
- Share feedback on MySQL community initiatives
- Join discussions around developer, DBA, ecosystem, cloud, AI, performance, and observability topics
- Respond to polls and other community engagement requests

GitHub Discussions are intended for open community conversation. For bugs or product defects, please use the appropriate MySQL bug reporting channels.
